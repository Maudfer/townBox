# Settings & Objects — content planning pass

This document is a content-planning artifact for TownBox's future object system: a runtime
`objects.json` of object archetypes that people can own, carry, and interact with. It is a
**data-name planning pass only** — no gameplay metadata is authored here. Each section below is a
real-world *setting* (a location, room, or context; 54 in total), followed by the concrete,
human-interaction-scale objects you would expect to find there: pocketable items, carryable items,
consumables, and placed equipment/furniture (still valid archetypes, just not portable). Object
names are singular, lowercase, concrete nouns. The deduped union of all lists lives in
[`objects-master-list.md`](objects-master-list.md), which adds a category and a rough portability
guess per object.
