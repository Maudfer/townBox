# Objects master list — content planning pass

This is the deduplicated master list of object-archetype names planned for TownBox's future
runtime `objects.json` — things people can own, carry, consume, or interact with. It is the union
of every per-setting object list in [`settings-and-objects.md`](settings-and-objects.md) (54
settings, 1565 raw entries), deduplicated to **1506 unique objects**. Each row carries a broad
category (one of the 21 categories below; household cleaning supplies are folded into
*hygiene/cleaning*, pet supplies land in *misc*), 1–3 example settings for traceability, and a rough
first-pass **portability guess** (`pocketable` / `carryable` / `heavy` / `fixed`) — final metadata
(prices, interactions, sprites, exact portability) is authored later.
